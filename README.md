# 🎡 최고급 전통 카지노 유러피언 룰렛 (European Roulette VIP)

핸드폰(스마트폰)과 PC 환경 모두에서 플레이 가능한 최고급 전통 카지노 스타일 유러피언 룰렛 웹 게임입니다.

---

## 📌 주요 특징 및 기능

### 1. 6개 카지노 룸(Room) 로비 시스템
* **Room 1: 모나코 클래식 (Monaco Classic)** — 베팅 한도: 1,000 ~ 500,000 KRW
* **Room 2: 라스베이거스 벨라지오 (Bellagio Suite)** — 베팅 한도: 5,000 ~ 2,000,000 KRW
* **Room 3: 몬테카를로 로열 (Monte Carlo Royal)** — 베팅 한도: 10,000 ~ 5,000,000 KRW
* **Room 4: 마카오 갤럭시 VIP (Galaxy VIP)** — 베팅 한도: 50,000 ~ 10,000,000 KRW
* **Room 5: 런던 리츠 프라이빗 (The Ritz Private)** — 베팅 한도: 100,000 ~ 20,000,000 KRW
* **Room 6: 두바이 엠페러 스위트 (Emperor Suite)** — 베팅 한도: 500,000 ~ 50,000,000 KRW
* 룸별 최근 10회 당첨 기록 보드, 핫(Hot) & 콜드(Cold) 번호 통계, 착석 인원 실시간 표시

### 2. 전통 카지노 정통 비주얼 & 디자인
* **유러피언 37칸 휠 (0~36)**: 실제 유러피언 카지노 번호 배치 순서 준수 (하우스 엣지 2.7%)
* **전통 룰렛 다이 테이블**: 딥 에메랄드 그린 펠트, 마호가니 원목 프레임, 황동 골드 격자선
* **모바일 & PC 완벽 반응형**: 스마트폰 터치 조작 및 PC 마우스 클릭 모두 최적화

### 3. 실감 나는 물리 사운드 & 여성 딜러 음성
* **Web Audio API 합성 사운드**:
  * 구슬이 트랙을 고속으로 질주하는 회전 마찰음
  * 포켓 프렛(격벽)에 부딪히며 통통 튕기는 실감 나는 탄성 타격음
  * 번호 홈에 딸깍 안착하는 묵직한 착지음
  * 칩을 놓을 때의 찰진 세라믹 사운드
* **여성 관리자/딜러 목소리 안내**:
  * 베팅 시작: *"Place your bets. 베팅을 시작해 주세요."*
  * 베팅 마감: *"No more bets! 더 이상 배팅할 수 없습니다."*
  * 당첨 번호 낭독: *"17번, 블랙, 홀수입니다. (Number 17, Black, Odd)"*
  * 당첨 축하: *"축하합니다! 승리하셨습니다. (Congratulations!)"*

### 4. 당첨 번호 돌리(Dolly) 핀 세우기 & 플레이어 적중 연출
* 번호 결정 시 실제 카지노처럼 테이블의 당첨 번호 위에 **황동 돌리 핀**을 상단에서 내려와 쿵 세워주는 3D 연출
* 테이블에 함께 착석한 가상 VIP AI 플레이어들과 함께 베팅하고 적중 시 상금과 축하 이펙트 표시
