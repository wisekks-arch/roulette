# 🎰 Lucky Roulette (럭키 룰렛) - 프리미엄 카지노 유럽식 룰렛

핸드폰(스마트폰)과 PC 환경 모두에서 실시간으로 플레이 가능한 최고급 카지노 정통 유럽식 룰렛 웹 서비스입니다.

---

## 📌 주요 특징 및 기능

### 1. 3단계 카지노 룸(Room) 로비 체계
* **초급방 (Beginner)**: 한도 100 ~ 10,000 Chip — 부담 없이 룰렛을 즐길 수 있는 입문자 룸
* **일반방 (Standard)**: 한도 1,000 ~ 100,000 Chip — 전통 카지노 분위기의 스탠다드 룸
* **VIP방 (High Roller)**: 한도 10,000 ~ 10,000,000 Chip — 고액 배팅과 프라이빗 혜택의 VIP 룸
* 각 방별 실시간 접속자 수, 현재 진행 회차(ROUND #), 남은 배팅 시간 및 최근 당첨 결과 5~6개 배지 표시

### 2. 10단계 표준 게임 시나리오 루프
1. **배팅 시간 (15초)**: 카운트다운 타이머 및 배팅 오픈 안내 멘트
2. **배팅 마감**: "BET CLOSED" 음성 멘트 및 땡!! 종소리 알림
3. **룰렛 회전 (6~8초 감속 물리)**: 휠 가속 ➔ 구슬 질주 ➔ 감속 바운스 ➔ 포켓 안착
4. **결과 발표 & 하이라이트**: 당첨 포켓 황금 스포트라이트, 크리스탈 말머리 돌리 핀 세우기
5. **정산 및 축하**: 당첨 시 코인 사운드(+Chip) 및 대형 축하 팝업
6. **다음 회차(NEXT ROUND) 자동 전환**: 3초 후 칩 수거 및 새 회차 생성

### 3. 배팅 편의 기능 및 자동화
* **Undo (마지막 배팅 취소)**: 직전에 배치한 배팅 칩을 1단계 취소 및 잔액 복구
* **자동 배팅 (Auto Play)**: 반복 횟수(회), 목표 수익 도달 시 자동 정지, 손절가 보호 설정
* **칩 단위 확장**: 100, 500, 1K, 5K, 10K, 50K, 100K, 500K 8개 세라믹 칩 제공

### 4. 실시간 데이터 통계 & 카지노 관리자 패널
* **실시간 통계 모달**: 최근 100회 분석 차트(레드/블랙, 홀/짝, 다즌 비율), 핫(Hot) & 콜드(Cold) 번호, 개인 전적(승률, 최고 당첨금)
* **카지노 관리자(Admin) 콘솔**: 활성 회원 모니터링, 하우스 엣지/배당률 설정, 회차별 정산 로그 테이블

### 5. 프리미엄 디자인 & 사운드
* **카지노 공식 컬러 팔레트**: 다크 그린(`#0F5132`), 매트 블랙(`#111111`), 카지노 레드(`#D62828`), 24K 골드(`#FFD700`)
* **Web Audio API 오디오**: 카지노 재즈 라운지 BGM 무한 루프, 시작/마감/구슬 충돌음/코인 획득음
* **세련된 딜러 음성**: 영국식/미국식 정통 카지노 여성 딜러 음성 안내
