# 🎰 Lucky Roulette (럭키 룰렛) - 프리미엄 카지노 유럽식 룰렛

핸드폰(스마트폰)과 PC 환경 모두에서 실시간으로 플레이 가능한 최고급 카지노 정통 유럽식 룰렛 웹 서비스입니다.

---

## 📌 주요 특징 및 기능

### 1. 4개 카지노 룸(Room) 로비 체계 (각 룸 최대 정원 8명)
* **초급방 (모나코 클래식)**: 한도 100 ~ 10,000 Chip — 부담 없는 소액 칩으로 즐기는 입문자 룰렛 테이블
* **일반방 (라스베이거스 벨라지오)**: 한도 1,000 ~ 100,000 Chip — 정통 카지노 분위기의 스탠다드 룸
* **고급방 (마카오 갤럭시 VIP)**: 한도 5,000 ~ 500,000 Chip — 화려한 황금빛 아시아 최대 카지노 하이롤러 룸
* **VIP방 (두바이 펜트하우스)**: 한도 10,000 ~ 10,000,000 Chip — 초호화 7성급 펜트하우스 VVIP 최고 한도 프라이빗 룸
* 각 방별 실시간 참석 인원(`현재인원 / 8명`), 진행 회차(ROUND #), 남은 배팅 시간 및 최근 10회 결과 배지 표시

### 2. 다중 봇 플레이어(2~3명)의 실시간 테이블 배팅 가시화
* **테이블 상단 참석자 바**: 나(YOU)와 함께 착석한 봇 플레이어(제임스 🇬🇧, 엘레나 🇲🇨, 마이클 🇺🇸) 및 빈 좌석(최대 8명) 실시간 표시.
* **플레이어별 고유 색상 칩 스택**: 테이블 번호 및 바깥쪽 배팅 구역에 나(골드) 외에 다른 참석자들의 칩(블루, 퍼플, 에메랄드 칩)이 실시간으로 함께 놓여지는 모습을 직접 확인 가능.

### 3. 실사 룰렛 구슬 낙하 라이브 캠 클로즈업 팝업 연출
* 배팅 마감(BET CLOSED) 직후, 화면 중앙에 **"🔴 LIVE CASINO CAM"** 시네마틱 팝업창이 등장.
* 고해상도 룰렛 휠과 은구슬이 트랙을 고속으로 질주하다가 핀에 부딪히며 포켓 안으로 쏙 떨어지는 박진감 넘치는 클로즈업 연출을 선보인 후 당첨 결과 화면으로 자동 전환.

### 4. 구슬 안착 번호와 결과 번호의 100% 영구 일치 보장
* 회차별 당첨 번호(`winningNumber`)를 단일 진실 소스(Single Source of Truth)로 락인.
* **실사 라이브 캠 구슬 안착 포켓 = 메인 휠 구슬 위치 = 테이블 크리스탈 말머리 돌리(Dolly) 핀 = 배당 정산기 = 딜러 음성**이 단 1개의 번호로 100% 오차 없이 완벽 동기화.

### 5. 10단계 표준 게임 시나리오 루프
1. **배팅 오픈 (15초)**: 카운트다운 타이머 및 딜러 음성, 봇들의 순차적 테이블 칩 배치
2. **배팅 마감**: "BET CLOSED" 음성 및 카지노 차임 벨 땡!! 소리 + 테이블 잠금
3. **실사 룰렛 구슬 낙하 라이브 캠 팝업**: 6~8초 감속 물리 회전 및 클로즈업 안착
4. **결과 발표 & 하이라이트**: 당첨 포켓 황금 스포트라이트, 크리스탈 말머리 돌리 핀 세우기
5. **정산 및 축하**: 당첨 시 코인 아르페지오 사운드(+Chip) 및 대형 축하 팝업
6. **다음 회차(NEXT ROUND) 자동 전환**: 3.5초 후 칩 수거 및 새 회차 자동 시작

### 6. 배팅 편의 기능 및 자동화
* **Undo (마지막 배팅 취소)**: `[↩ 취소 (UNDO)]` 버튼으로 방금 올린 칩 1단계 취소 및 잔고 즉시 복구
* **자동 배팅 (Auto Play)**: 반복 횟수(회), 목표 수익 도달 시 자동 정지, 손절가 보호 설정
* **칩 단위 확장**: 100, 500, 1K, 5K, 10K, 50K, 100K, 500K 8개 세라믹 칩 제공

### 7. 프리미엄 디자인 & 재즈 BGM
* **카지노 공식 테마 컬러**: 다크 그린(`#0F5132`), 매트 블랙(`#111111`), 카지노 레드(`#D62828`), 24K 골드(`#FFD700`)
* **카지노 재즈 BGM**: Web Audio API 내장 신디사이저로 부드러운 라운지 재즈 화음 무한 루프 재생
